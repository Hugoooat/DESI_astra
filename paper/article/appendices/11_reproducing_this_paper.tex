\section{Reproducing this paper}
\label{app:repro}
% =====================================================================

\paragraph{Code.} All the measurements, forecasts and figures are produced by the code at \url{https://github.com/Hugoooat/DESI_astra/tree/astra_hugo_v2}, run on NERSC Perlmutter CPU nodes with the DESI \texttt{cosmodesi} environment:
\begin{lstlisting}[language=bash]
source /global/common/software/desi/users/adematti/cosmodesi_environment.sh main
\end{lstlisting}
The code is organised in three modules and a set of scripts: \texttt{astra\_ds.py} contains the whole measurement of one catalogue (reading, periodic padding, ASTRA tessellation, density field, quartiles, subvolumes, clustering), \texttt{analysis.py} the loading of measurements, data vectors, covariances and Fisher tools, \texttt{emulator.py} the emulator (networks, training with the difference loss, derivatives). Each catalogue is measured on one 128-core node in $\simeq8$ minutes (64 subvolumes processed in parallel, ASTRA and density split, 33 statistics, three multipoles); measurements are saved as one \texttt{.npz} file per catalogue, line of sight and space, containing the multipoles of every statistic for every subvolume. Lists of catalogues are run with \texttt{slurm/run\_list.sh} inside an allocation (one \texttt{srun} per node).

\paragraph{Data.} The three data sets of Table~\ref{tab:datasets} are read from the following locations on NERSC:
\begin{itemize}
\item \textbf{AbacusSummit emulator suite}: \texttt{/pscratch/sd/n/ntbfin/emulator/hods/z0.5/yuan23\_prior/c\{CCC\}\_ph000/seed0/hod\{NNN\}.fits} (85 cosmology directories, \texttt{hod000}--\texttt{hod499}); cosmological parameters in \texttt{config/cosmologies.csv}. The catalogues measured are listed, one line per catalogue (cosmology, HOD, space, line of sight), in \texttt{config/runs\_emulator*.txt} (8 HODs per cosmology), \texttt{runs\_hod\_calibration.txt} (72), \texttt{runs\_local\_*.txt} (240), \texttt{runs\_extra.txt} (54) and \texttt{runs\_real\_space.txt} (27); the fiducial catalogue and the HOD-matched pairs are in \texttt{config/hod\_selection.json}.
\item \textbf{Official DESI mocks}: \texttt{/global/cfs/cdirs/desi/cosmosim/AbacusHOD\_mocks/v1/CovBox/LRG/z0.500/catalog\_rsd\_xi2d\_lrg\_main\_z0.5\_velbias\_mockcov\_ph\{3000+\}.fits} (1786 files) and \texttt{.../CubicBox/LRG/z0.500/AbacusSummit\_base\_c000\_ph\{000--024\}/}.
\item \textbf{Quijote}: Rockstar halo catalogues \texttt{\{set\}/\{i\}/out\_3\_pid.list} for the sets \texttt{fiducial} (realisations 0--3999), \texttt{fiducial\_ZA}, \texttt{Om\_p/m}, \texttt{Ob2\_p/m}, \texttt{h\_p/m}, \texttt{ns\_p/m}, \texttt{s8\_p/m}, \texttt{Mnu\_p/pp/ppp} (realisations 0--499), transferred with Globus from the Quijote public data to \texttt{/pscratch/sd/h/hugon/quijote/}, following the instructions of the Quijote documentation (\url{https://quijote-simulations.readthedocs.io}).
\end{itemize}
Intermediate products (measurements, trained emulators, chains; $\simeq3$\,GB) are stored in \texttt{/pscratch/sd/h/hugon/astra-ds-store/} and are regenerated by the steps below.

\paragraph{Steps.}
\begin{lstlisting}[language=bash]
python scripts/select_hods.py; python scripts/select_runs.py; python scripts/select_local_runs.py
salloc ... bash slurm/run_list.sh config/runs_*.txt     # measurements
sbatch slurm/night_stage1.sbatch                         # official mocks + Quijote
python scripts/build_emulator_dataset.py
python scripts/build_pair_dataset.py --holdout 0 --out pair_dataset_full.npz
python scripts/train_emulator.py --nseeds 10 --pairs data/pair_dataset_full.npz --models-dir models_pairs --tag _pairs
python scripts/compare_methods.py --models-dir models_pairs --validation-tag _pairs --compress --cov covbox --fiducial official --params omega_b omega_cdm n_s sigma8 w0 wa
python scripts/quijote_fisher.py --params Om s8 --rebin 2 --tag _p0c0; python scripts/summarize_quijote.py
python scripts/mcmc.py --data official:000:0 --vector ASTRA --cov covbox --volume-factor 1; python scripts/summarize_mcmc.py
bash slurm/quijote_classes.sh                           # ASTRA classes on Quijote (run_quijote.py --classes)
python scripts/quijote_classes_fisher.py --params Om s8 --tag _p2; python scripts/classes_figures.py
python scripts/robustness.py; python scripts/plot_real_space.py
python scripts/paper_figures.py --params omega_b omega_cdm n_s sigma8 w0 wa
python scripts/paper_figures_v1style.py --params omega_b omega_cdm n_s sigma8 w0 wa
python scripts/readable_figures.py; python scripts/env_maps.py; python scripts/classes_figures.py
cd paper && make                                       # article, article_fr, vulgarisation, poster
\end{lstlisting}
The full set of measurements costs $\simeq200$ node-hours (1043 emulator-suite catalogues, 1786 small boxes and 25 base boxes, 11\,000 Quijote realisations at $\simeq5$\,s each).
